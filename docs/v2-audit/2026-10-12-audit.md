# V2 public-data audit — 2026-10-12

Baseline: `8e711eb9d7378a8503575522bba453f4cb2a2740`.

The existing preview test passes, but the generated data does not yet meet multilingual acceptance requirements. This PR adds a read-only auditor that reports unresolved text instead of treating an empty catalog row as a completed translation. Production pages and V1 generators are unchanged.

## Reproducible findings

- Official catalog: 16,207 keys; 749 empty rows per language (741 absent references plus 8 source rows empty in all four languages).
- Custom: 468 keys; Thai/Japanese empty. UI: 731 keys; Thai/Japanese empty.
- Seven implicit Skill+ / Spec+ effect translation keys are absent (15 references), missed by the previous scan.
- 55 artifact effects reference `%d` without passing their stored percentage.
- 33 Spec+ descriptions contain native game placeholders without a binding.
- One BLOODLUST effect references `%d` without arguments.
- Six catalog keys contain control characters; three originate in official language data, three in generated references. These require different handling.
- The auditor reports 1,117 empty text reference occurrences and 244 unbound placeholder language occurrences, across 89 data locations. These are issue counts, not completed translations.

## Compiler audit findings

The raw `subSkills` field is a comma-separated list of codes. The current normalizer only accepts child objects, so the parent skill survives while child effects disappear. Raw-table verification identified 5,386 missing effects across 1,763 Ranger records and 917 missing effects across six enemy categories. Counts in the manifest cannot reveal this defect. Expand the official skill index in memory, preserve source order, and reject missing references.

Additional work: major talent secondary conditions, missing enemy metadata, native Spec+ formatting, nested missing-text propagation, numbered placeholder reordering, and transactional candidate validation before promotion. Keep official missing translations explicit and preserve authored custom/UI catalogs during automatic refreshes.

`--strict` intentionally fails on unresolved findings. The baseline JSON records the public input state. The complete private audit and deployment inventory are retained separately and are not included in the public repository.

The existing static UI test incorrectly checks the V2 page using the V1 UI catalog; fix it by following each page's actual catalog, not by copying V2 text into V1. The standalone `/v2/` preview is not evidence that the production site's 42 pages are multilingual.
