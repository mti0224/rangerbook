# 全站翻譯補齊（2026-10-21）

本次新增 138 組繁體中文、英文、泰文、日文詞條，放在前端維護的 `assets/locales/sitewide-overrides.json`。V2 與一般 i18n 載入器共用這份檔案；它會覆蓋定時發布的舊 UI 快照，避免後端資料發布把本次修正洗掉。原始遊戲資料、分類值、搜尋值與帳號識別碼不變。

## 修正範圍

- 補齊角色／裝備詳細頁、載入失敗、篩選無障礙標籤、動畫預覽與目標選項、側欄開合標籤。
- 管理員權限、密碼重置、刪除帳號的原生確認視窗改用明確鍵值與參數。帳號名稱不參與自動句型比對，也不變更實際操作。
- 補齊註冊、變更密碼、API 錯誤、審核狀態、申請日期、流量與資源追蹤訊息；角色／狀態組合文字在組合前翻譯。
- 補齊 PvP 歷史圖表的 canvas 空狀態、使用次數、移除按鈕及錯誤訊息；歷史名稱依 Ranger ID 取官方翻譯。
- 詳細頁瀏覽器標題、公會戰說明、裝備組合與分頁標籤使用明確參數，避免中文和外語混用。
- 共用類型／屬性文字固定優先採用 tag 詞條；分析區的簡稱維持使用明確鍵值，不再因定時發布檔案的詞條排列順序而改變其他頁面的顯示。
- 裝備強化下拉選單的隱藏標籤與 aria-label 翻譯完整句子；實際 section 與 option value 保持不變。
- i18n 監聽後續修改的 title、placeholder、aria-label、alt 與明確翻譯鍵，並避免相同屬性重複寫入。
- 相同中文可能對應不同的官方外語說明。技能及主要才能攜帶原本的文字鍵，能力沿用已有的鍵；各顯示器依鍵呈現，避免把相同中文的不同官方譯文視為歧義而保留中文。
- PWA 離線啟動清單納入新增翻譯檔。Pages 建置仍由 `scripts/build-pwa.mjs` 產生完整發行清單。

## 驗證

- 43 個正式 HTML 頁面 × 英／泰／日文，共 129 次瀏覽器檢查；無 pageerror。繁體中文的整合回歸另行驗證。
- 額外檢查角色與裝備詳細頁、關卡、能力、敵人等 9 個資料畫面 × 3 語言；因此找到並修正泰文迷宮卡片的 `關卡 N-M` 漏翻。
- `tests/sitewide-localization.cjs` 四語系通過：動態屬性、數值句型、角色詳細資料、等級調整、裝備強化標籤、canvas 空狀態、原生確認視窗與 API 錯誤。另驗證同中文的兩份才能說明仍各自使用其官方英文譯文。
- 原有 UI 覆蓋、詳細表格與使用者審核詞彙測試通過；i18n contract、V2 adapter 四語系 × 18 種 view contract 通過。
- 全部前端 JavaScript 語法檢查通過。
- 同步修正舊整合測試的預期：管理頁預設為既有的「個人隊伍」，超進化沿用 `Hyper N Stars` 命名；管理頁測試改用 finally 關閉瀏覽器，失敗時不再讓工作卡到逾時。

關於本站中的測試者暱稱、公會名稱及玩家名稱保留原樣。官方來源本身不存在的文字鍵仍保留既有的 ID／備援行為；不捏造官方名稱。獨立 `/v2/` 資料檢視工具以其頁內語言選單為準，與正式網站的語言設定分開。

## 後續維護

新增介面詞條時，使用穩定的 `UI:site.*` 鍵並同時填寫四種語言。含名稱、日期或錯誤細節的句子要使用 `format()` 明確傳入參數；僅純數字的完整句型可用自動比對。新增 DOM 後仍需確認 canvas、原生視窗與 aria 屬性，不能只檢查畫面文字節點。
