# 2026-10-22 網站安全檢查與修正

範圍為公開網站、登入與管理 API、實際後端依賴、Pages 發布內容，以及正式服務的反向代理、檔案權限與 EC2 網路設定。使用隔離資料庫與假帳號驗證修改，不對真實使用者執行密碼重設或帳號變更。此為程式與設定檢查，不能保證不存在其他漏洞。

| 問題 | 可能影響 | 修正 |
| --- | --- | --- |
| 正式環境 certifi 與 pip 含已公告問題 | 受影響 CA 信任根；安裝時遭惡意套件索引利用 | certifi 更新至 2026.10.19、pip 更新至 26.2.2；加入 certifi 最低版本與 CI 依賴稽核 |
| 登入及敏感操作沒有嘗試次數限制 | 暴力猜密碼、重複昂貴雜湊或官方 API 呼叫 | SQLite 原子記錄成功與失敗嘗試，依 IP 及帳號限流，回傳 429；Argon2 同時最多兩個；Nginx 加入請求速率及本文大小限制 |
| 重設密碼使用固定公開值 | 被重設帳號可能遭接管 | 每次產生隨機臨時密碼、撤銷既有 session，首次登入強制換密碼；伺服器端阻擋尚未更換密碼的管理存取 |
| 私有 API 沒有明確禁止快取 | 登入狀態及管理資料可能留在瀏覽器或代理快取 | 私有 API 使用 no-store、private，前端請求也禁止快取；公開統計仍保留公開快取 |
| 資料庫可由其他本機使用者讀取，程式與資料共用可寫目錄 | 帳號與 session 雜湊外洩，服務遭入侵後可能修改程式 | DB 權限 0600、UMask 0077；DB 及玩家快取移至私有目錄；服務程式與虛擬環境唯讀，遮蔽 SSH/AWS 使用者憑證目錄 |
| Pages 上傳整個儲存庫 | 後端及維運檔案成為公開站點內容 | 明確白名單打包至 _site，只發布網站檔案；排除後端、部署、測試、私有資料格式與符號連結 |
| API 本文大小及錯誤資訊缺少限制 | 記憶體耗用，輸入值或內部錯誤資訊回傳 | 本文含串流上限 16 KiB；驗證錯誤不含輸入內容，內部錯誤回傳通用訊息 |
| 登出失敗仍清除前端登入顯示 | 使用者誤以為伺服器 session 已失效 | 確認伺服器成功撤銷 session 後才清除前端狀態，失敗明確顯示 |
| 缺少部分 API 防護標頭、正式 API 公開互動文件 | 不必要的瀏覽器解讀及介面資訊暴露 | nosniff、禁止嵌入、限制 CSP、HSTS、no-referrer；關閉正式 API 文件與 schema 端點 |

## 驗證

- 後端 30 項測試：匿名及跨角色拒絕、Origin、Cookie 屬性、限流、密碼重設與首次換密碼、session 撤銷、檔案權限、錯誤遮蔽與串流大小。
- 前端隔離瀏覽器測試：繁中、英文、泰文、日文的首次換密碼、管理區保護、登出成功/失敗與隨機密碼顯示。
- Pages 產物測試：公開檔案保留，後端、秘密檔案、資料庫、來源映射與符號連結排除。
- 實際安裝的後端套件清單以 pip-audit 重新掃描；依賴稽核結果受公告資料庫及檢查時間限制。
- 正式環境驗證不登入真實帳號，僅查健康狀態、匿名拒絕、回應標頭、服務隔離與檔案權限。

## 原本已有的保護

管理 API 在後端驗證權限，敏感寫入檢查允許的 Origin，session Cookie 使用 Secure、HttpOnly、SameSite 及 __Host- 前綴。EC2 安全群組沒有公開 SSH、Auth 僅監聽 localhost、IMDSv2 已強制。前端隱藏遊戲項目不構成資料保密：公開遊戲 JSON 仍屬公開資料。

## 維護

更新後端程式需由部署流程執行，服務本身不能改寫程式碼。維護資料庫及執行 bootstrap 時，必須使用 systemd 路徑設定中的同一份私有資料庫。保留受限權限的回復備份，禁止將資料庫或環境憑證放入 Pages 或版本控制。
