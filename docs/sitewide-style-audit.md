# 全站 Game-Tech 視覺驗收

## 靜態盤點
- \`40\` 個 HTML 路由。
- \`52\` 個原有 CSS 檔案分散定義工具列、按鈕、選取狀態、彈窗和表格。
- \`theme-toggle.css\` 曾對所有深色模式按鈕的 \`:hover\` 強制套用亮藍色，與 Game-Tech 介面衝突。
- \`ability/index.html\` 等頁面引用 \`ranger-ability-effect-merge.css\` 但主分支缺失。
- 另有 Ranger 動畫、等級控制、裝備條件、PvP 歷史、迷宮、管理員展開選單等元件各自保有舊樣式。
- 不更改角色、屬性、覺醒、星級等語意標籤的分類顏色。

## 修改策略
1. 將深色 \`button:hover\` **全域選擇器**縮限為原本需要的導覽與分頁控制。
2. 在 \`game-tech-controls.css\` 定義明暗兩組低飽和控制項色彩與交互狀態；與 \`game-tech.css\` 分層載入。
3. 以確切的按鈕／選單 class 與 ID 進行視覺整合；不更動事件處理或資料來源。
4. 補齊缺失的 \`ranger-ability-effect-merge.css\`，統一動態能力效果表格。
5. 增加 Chromium 實際渲染測試，每個入口渲染深色／淺色和桌面／手機，共 **160** 個情境，輸出截圖與可解析的 \`results.json\`。

## 測試與限制
- 檢查主題、共用 CSS 是否載入、頁面水平溢出、可見控制項亮色背景、空白卻顯示的建議選單及瀏覽器錯誤。
- 僅提供匿名／公開頁面截圖，管理員登入後頁面需要經授權的帳號另行驗收。
- 對網站裡需要資料才顯示的列表與彈窗，仍需人工補充操作測試。
- 這份報告使用本次 PR 的**本地預覽伺服器**生成，而不是已部署的正式網站；PR 合併後才會出現在正式站。
- 沒有核准過的截圖基準，因此首次測試以蒐集問題為主，不能單靠比較像素宣稱所有畫面都正確。


## 第一輪 Chromium 執行
- 160/160 初始情境成功渲染、無測試導航失敗。
- 檢查程序發現 82 個旗標，其中 80 個來自錯誤使用 \`/ranger/ranger/index.html\` 入口，2 個來自公會戰限定頁的匿名權限導向，非已確認的 CSS 漏樣式。
- 修正瀏覽器驗收的正式入口為帶尾斜線的路由，將匿名限定頁另行註記，不再誤列為未載入樣式。
- 第二輪加入 settings、Ranger、裝備、能力、PvP 彈窗（資料允許時）的開啟狀態截圖。
- 人工檢視第一輪多頁截圖可見裝備／敵人列表分頁有深藍底次要按鈕未與青綠系統一致，因此補上準確選擇器，避免重複使用全站 button:hover 覆蓋。
